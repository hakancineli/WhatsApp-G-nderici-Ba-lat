# 🚀 Railway ile Hızlı Deployment

## Adım 1: Railway Hesabı
1. [Railway.app](https://railway.app) git
2. GitHub ile giriş yap

## Adım 2: Proje Deploy Et
1. "New Project" → "Deploy from GitHub repo"
2. Bu repo'yu seç: `WhatsApp-G-nderici-Ba-lat`
3. "Deploy Now" tıkla

## Adım 3: Environment Variables
```
NODE_ENV=production
HEADLESS=true
PORT=3000
```

## Adım 4: QR Kod Okut
1. Railway'den verilen URL'e git (örn: `https://whatsapp-sender-production.up.railway.app`)
2. QR kodu telefonla tarat
3. WhatsApp Web bağlantısı kurulur
4. Mesaj göndermeye başla!
